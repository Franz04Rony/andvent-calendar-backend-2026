# Backend

Servidor del calendario de adviento y guardián de las sorpresas.

Guarda el contenido de los 26 días (cartas, fotos, videos y demás) y decide, con su propio reloj y la hora de Lima, qué días ya están desbloqueados. Solo entrega una sorpresa cuando llega su fecha, así que no hay forma de verla antes de tiempo desde el navegador.

Hecho con Node.js.
